## Cara membaca metrik

- **Makespan**: detik dari awal penjadwalan batch sampai respons task terakhir diterima scheduler (termasuk overhead jaringan).
- **Estimated Compute Cost (USD)**: `(tarif host1 + tarif host2) x makespan / 3600`. Estimasi biaya komputasi dua host selama makespan, bukan tagihan Azure sebenarnya (tagihan juga mencakup waktu VM menyala di luar pengujian, disk, IP publik, dll.).
- **Resource Utilization (%)**: akumulasi waktu eksekusi task / (jumlah worker x makespan) x 100. Ini utilisasi waktu kerja worker, bukan `Percentage CPU` Azure, dan tidak dibobot kapasitas CPU worker.
- **Degree of Imbalance**: (sibuk maks - sibuk min) / rata-rata sibuk antarworker. Makin dekat 0 makin merata waktu sibuknya. Bukan ukuran jumlah task; lihat tabel jumlah task per worker.
